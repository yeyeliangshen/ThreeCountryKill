# 武将原画

把图片按 **`<武将 id>.jpg`** 放进这个目录就会自动生效，不需要改代码。

文件名必须用武将 id（不是中文名），id 见 `packages/engine/src/heroes.ts`，例如：

| 文件 | 武将 |
| --- | --- |
| `guanyu.jpg` | 关羽 |
| `sunquan.jpg` | 孙权 |
| `zhouyu.jpg` | 周瑜 |
| `diaochan.jpg` | 貂蝉 |

- 支持的扩展名：`.jpg` `.jpeg` `.png` `.webp`
- 尺寸建议 **220×311 上下**（比例 1 : 1.415，和卡牌一致）。面板里的原画最大显示到 220 宽，
  窄屏缩到 148 宽；文件做成 2 倍（约 440×622）可以在高分屏上更清晰。
- **没有对应文件的武将会自动回退**成「名字竖排」的占位框，所以可以只放一部分，不用一次补全。
  目前中立武将「平民」（id `vanilla`）就没有原画。

替换成自己的图：按上面的文件名覆盖即可，刷新页面生效。
