# 武将原画

把图片按 **`<武将 id>.jpg`** 放进这个目录就会自动生效，不需要改代码。

文件名必须用武将 id（不是中文名），id 见 `packages/engine/src/heroes.ts`，例如：

| 文件 | 武将 |
| --- | --- |
| `guanyu.jpg` | 关羽 |
| `sunquan.jpg` | 孙权 |
| `zhouyu.jpg` | 周瑜 |
| `diaochan.jpg` | 貂蝉 |

- 支持的扩展名：`.jpg` `.jpeg` `.png` `.webp`
- 尺寸 **440×622**（比例 1 : 1.414，和卡牌一致）。面板里原画最大显示到 220 宽、窄屏缩到 148 宽，
  440 宽正好是 2 倍图。
- **没有对应文件的武将会自动回退**成「名字竖排」的占位框，所以可以只放一部分，不用一次补全。

替换成自己的图：按上面的文件名覆盖即可，刷新页面生效。

## 现在有哪些（2026-09 补全）

123 位武将里 **119 位**有原画，4 位留空：

- `平民` / `崩坏` / `勇决`：中立白板 / 技能化身占位武将，本来就没有官方原画；
- `崔琰毛玠`：资源包里只有分开的「崔琰」「毛玠」两张，没有合体立绘。

每位武将用的是哪张图、走的哪条取图口径（国战版 → 界版 → 普通版 → 留空），
完整对应关系见 **`docs/hero-art-map.md`**。
