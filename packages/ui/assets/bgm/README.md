# 背景音乐文件

把音乐文件放进这个目录就会自动生效，**不需要改代码**。

## 命名规则

文件名（不含扩展名）决定用在哪个场景，优先级从高到低：

| 文件名 | 用在哪 |
| --- | --- |
| `menu.*` | 进房前：填地址、大厅选将之前 |
| `battle.*` | 对局中 |
| `default.*` | 上面两个都没放时，所有场景共用 |

支持的扩展名：`.mp3` `.ogg` `.m4a` `.mp4` `.wav`。

**当前用的是 `default.mp4`**（三国杀开局音乐，来自爱给网），所以菜单和对局里都放这一首。
想给对局换一首，放 `battle.mp3` 进去即可，它会盖过 `default`；想给菜单单独换就放 `menu.mp3`。

## 行为

- 找到文件 → 循环播放该文件，音量跟右上角的声音开关 / 音量条走。
- 文件加载或解码失败 → 右上角提示一句，并自动退回内置合成音，不会静默没声音。
- 完全没放文件 → 直接用内置的 Web Audio 合成音（五声音阶循环）。
- 想要淡入淡出、多段循环等更复杂的效果，改 `src/audio/bgm.ts` 的 `startFile()`。

## 注意

- **`default.mp4` 是带视频轨的 MP4**（H.264 + AAC），约 4.9 MB，其中绝大部分是没用的视频数据。浏览器用 `<audio>` 指向它是能正常出声的，所以先这么用着。要瘦身可以用 ffmpeg 抽出音频轨：
  ```bash
  ffmpeg -i default.mp4 -vn -c:a copy default.m4a   # 只留音轨，通常能降到 1 MB 以内
  ```
  换完记得删掉 `default.mp4`，否则两个文件都叫 `default`，会按上面表格的顺序取先匹配到的那个。
- 请自行确认所用音乐文件的授权。`default.mp4` 下载自爱给网，使用前请核对该素材的授权范围。
