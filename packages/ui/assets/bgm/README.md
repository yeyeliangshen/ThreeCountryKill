# 背景音乐文件

把音乐文件放进这个目录就会自动生效，**不需要改代码**。

## 命名规则

文件名（不含扩展名）就是场景名，目前支持两个场景：

| 文件名 | 用在哪 |
| --- | --- |
| `menu.mp3` | 进房前：填地址、大厅选将之前 |
| `battle.mp3` | 对局中 |

支持的扩展名：`.mp3` `.ogg` `.m4a` `.wav`。同名时按上面这个顺序取第一个被匹配到的。

## 行为

- 没有对应文件 → 用内置的 Web Audio 合成音（五声音阶循环，不需要任何文件）。
- 有文件 → 循环播放该文件，音量跟右上角的声音开关 / 音量条走。
- 想要淡入淡出、多段循环等更复杂的效果，改 `src/audio/bgm.ts` 的 `startFile()`。

## 注意

- 请自行确认所用音乐文件的授权。仓库里默认不放任何音频文件。
- 大文件会明显增加构建产物体积；构建后的 `packages/client/dist` 会一并打包。
