# 武将原画对应表（共 123 位武将）

资源包：`三国杀Online V4.1.8-2武将原画`（本地资源分享包，541 张）。
写入位置：`packages/ui/assets/heroes/<武将 id>.jpg`（440×622；面板显示 220 宽，这是 2 倍图）。

## 取图口径（按用户 2026-09 指定）

1. **优先国战版**（资源包里带 `【国战】` 标签的那张）；
2. 没有国战版 → **界版**（`界××`）；
3. 再没有 → **普通版**；
4. 都没有 → **留空**（界面自动回退成「名字竖排」的占位框）。

为了别拿错图，另外细化了两条：

- **势力优先于版本**：同势力的图优先。否则会出现「蜀·赵云」配「群·SP赵云」、
  「蜀·庞统」配「吴·SP庞统」这类跨势力立绘（资源包里的 SP / 神 系列是别的势力的卡）。
- **国战版内部**：先取与武将名版本一致的那张（`界钟会` 优先国战界版，没有就退国战基础版）；
  同名版本拿不到时取任意国战版（例：`马岱 / 于吉 / 左慈 / 法正 / 周瑜 / 小乔` 只有国战界版）。
