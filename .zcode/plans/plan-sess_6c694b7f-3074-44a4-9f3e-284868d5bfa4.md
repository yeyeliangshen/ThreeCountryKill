# 大厅 + 房间（主流联机卡牌那套规则）

## 规则

1. 连上服务器 → **大厅**：列出所有房间（房号 / 房主 / 人数 / 模式 / 状态），可以创建，也可以点进去。
2. **创建房间** → 你就是房主，自动坐 1 号位。房号服务端自动分配（4 位）。
3. **房主退出** → 房主自动移交给房间里另一个人；**房间没人了 → 房间消失**。
4. **对人数的判定看「有没有人占着座位」**，不看在不在线：离线/锁屏/刷新的人还算占着座位（所以他们能回来）。
5. **离开房间**：未开局 = 释放座位；对局中 = 只断开、座位保留（重连能接着打）。
6. 已开局的房间在大厅里**显示但进不去**（标记「游戏中」）；只有认回/接替一个**已有名字且离线**的座位才进得去。
7. **刷新/锁屏回来**：本机记住 {服务器, 房号, 昵称, 座位}，自动重连并认回原座位；房间里的**离线座位也可以点**（接替/换设备）。

## 改动

- **协议**：`join` 换成 `enterHall / createRoom / joinRoom / leaveRoom / claimSeat / listRooms`；服务端新增 `hall { rooms }`、`roomClosed { reason }`；`RoomSummary = { roomCode, hostName, players, maxSeats, mode, started }`
- **服务端**：大厅客户端集合 + `broadcastHall()`；房间生命周期（`leaveSeat` 含房主移交、`isEmpty` → 删房）；`claimSeat` 支持换座并释放原座位；删房只有一处入口
- **界面**：`JoinPage` 瘦身成「服务器地址 + 昵称 → 进入大厅」；新增 **Hall** 页（房间卡片网格 + 创建房间 + 用房间号加入）；`Lobby` 的「退出」改成「离开房间」，离线座位可点；对局结束补一个「离开房间」出口；`localStorage` 持久化身份
- **engine 完全不动**
