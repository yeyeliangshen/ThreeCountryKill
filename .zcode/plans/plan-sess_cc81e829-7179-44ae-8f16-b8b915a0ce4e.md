# Phase 3 — 三国杀规则完整复刻

## 总览

将引擎从"基础4牌+6技能"扩展为完整 SGS 规则系统。按依赖顺序分 10 步，每步可独立 typecheck + test + commit。从 `feature/modes` 拉 `feature/phase3` 分支。

## 关键设计决策

1. **CardType 扁平 union**：锦囊牌名直接作 CardType（`'juedou'`/`'nanman'`…），引擎直接 `switch(card.type)` dispatch 无需二次查表；装备牌按槽位分类（`'weapon'|'armor'|'plusMount'|'minusMount'`）+ `equipName` 存具体牌名。

2. **装备槽结构体**：`Player.equipment` 从 `Card[]` 改为 `{ weapon, armor, plusMount, minusMount: Card|null }`，同槽位装备时旧的进弃牌堆。

3. **距离公式**：`distance(from,to) = baseDistance − from的−1马 + to的+1马`；`attackRange = 1 + weapon.range`；杀/顺手牵羊需 `attackRange ≥ distance`。

4. **判定阶段**：回合流程改为 **判定→摸牌→出牌→弃牌→结束**。判定翻牌堆顶为判定牌，可被鬼才替换；延时锦囊按判定结果结算。

5. **主动技能框架**：新增 `useSkill` intent + `Hero.activeSkills` 注册表 + `skillUsedThisTurn` 限次标记。

6. **酒救人限1次/回合**：`taoSaveCountThisTurn` 计数。

### 延时锦囊放置

## Step 4 — 引擎：即时锦囊

### `model.ts` — Pending & TrickContext
- `TrickContext`: `{ sourceId; cardId; type: CardType; targetIds: string[]; askQueue: string[]; askIndex: number; ... }`
- `{ kind: 'respondTrick'; responderId: string; ctx: TrickContext }`

### `engine.ts` — `playTrick` dispatch
按 `card.type` 分发：
- **无中生有**：自己摸2张
- **过河拆桥**：弃目标1张(手/装/判，无距离限制)
- **顺手牵羊**：偷目标1张(距离≤1)
- **决斗**：目标先出杀→交替→不出者受1伤害
- **借刀杀人**：有武器目标→对指定角色出杀或交出武器
- **南蛮入侵**：其余存活依次出杀或受1伤害
- **万箭齐发**：其余存活依次出闪或受1伤害
- **火攻**：目标展示1手牌→弃同花色牌→1点火伤害
- **桃园结义**：所有存活回1体力(满不回)
- **无懈可击**：锦囊生效前插入询问轮(askQueue全体)，打出→该锦囊对指定目标失效→可被反无懈

### 无懈可击机制
- 每个即时锦囊生效前，插入一轮无懈可击询问
- 有人打出→该目标的效果取消→可被反无懈(再一轮)

**验收**：各锦囊效果正确；无懈可击能取消；多目标依次结算。

## Step 6 — 引擎：10 名待复刻武将技能

### canUseAs 转化（直接加）
- **甘宁·奇袭**：黑色牌当【过河拆桥】

### 被动 hook
- **马超·铁骑**：`becomeTarget` → 翻判定牌→红色则 `requiredShan=∞`（不可闪避）
- **黄忠·烈弓**：`becomeTarget` → 目标手牌≥己 或 体力≤己 → `requiredShan=∞`
- **吕布·无双**：`becomeTarget` → `requiredShan=2`；respondSha 出闪后减1，>0继续等
- **夏侯惇·刚烈**：`afterDamage` → 翻判定→非红桃则来源选择弃1牌或受1伤害

### 判定替换
- **司马懿·鬼才**：`beforeJudge` → 可打1手牌替换判定牌

### 主动技能
- **孙权·制衡**：弃任意张牌→摸等量
- **黄盖·苦肉**：失去1体力→摸2张

- **周瑜·反间**：展示1手牌交给目标→目标选择交回1张不同类型牌或受1伤害

### respondSha 改造（吕布）
- `requiredShan` 默认1；出闪后 `requiredShan--`，>0 则继续等闪

**验收**：10 技能各有测试用例；与装备/锦囊/判定交互正确。
