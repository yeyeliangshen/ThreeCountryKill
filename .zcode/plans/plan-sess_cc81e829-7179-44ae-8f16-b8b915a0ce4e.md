# 上云部署：node 同端口托管前端 + pm2 一键启停

## 目标
代码 push 到 GitHub → 服务器 `git clone` → `bash scripts/manage.sh start` 一键拉起 → 用户浏览器访问 `http://公网IP:8080` 直接拿到游戏页面、开房、打牌。`bash scripts/manage.sh stop` 关闭。dev 体验不变。

## 1. 服务端同端口出页面 + WS：`packages/server/src/index.ts`
- 引入 `node:http` / `node:fs` / `node:path`（零新依赖，保持项目无外部依赖风格）。
- 解析静态目录：`path.join(process.cwd(), 'packages/client/dist')`（prod 跑在仓库根，dist 存在）；不存在时打印警告但 ws 仍工作（dev 时 client 在 vite:5173，无 dist，不影响）。
- 建 `httpServer = http.createServer(serveStatic)`：按 URL 路径映射 dist 内文件，带 MIME 表（.html/.js/.css/.svg/.png/.ico/.json/.woff2）；文件不存在 → 回 `index.html`（SPA 兜底）。
- ws 改为挂到 httpServer：`new WebSocketServer({ server: httpServer })`（原 `{ port }` 改掉）；`httpServer.listen(PORT, '0.0.0.0')`。
- 效果：一个 8080 端口同时服务 HTTP（页面）和 WebSocket（游戏）。

## 2. 客户端 ws 地址自动同源：`packages/client/src/store.ts`
- `buildWsUrl(addr)`：`addr` 为空 → 返回 `ws://${location.host}`（部署后访问 `http://IP:8080` 自动连 `ws://IP:8080`）。
- `serverAddr` 默认值：`import.meta.env.DEV ? 'localhost:8080' : ''`（dev 仍默认 8080 不破坏现有开发；prod 默认空=用当前页 host）。
- 这样部署用户打开页面什么都不用填服务器地址，直接进。

## 3. JoinPage 提示：`packages/client/src/pages/JoinPage.tsx`
- 服务器地址框 placeholder 改为 "留空=当前服务器（如 localhost:8080）"。

## 4. pm2 进程配置：`ecosystem.config.cjs`（仓库根）
```js
module.exports = {
  apps: [{
    name: 'sgs',
    script: 'packages/server/src/index.ts',
    interpreter: 'node',
    node_args: '--import tsx/esm',   // 用本地 tsx 即时转译，无需编译 server/engine/protocol
    env: { NODE_ENV: 'production', PORT: 8080 },
    autorestart: true, max_restarts: 20,
  }],
};
```
- 走 tsx 直接跑源码（与 dev 同机制），只 build 客户端即可，不碰 server/engine/protocol 编译，契合项目"workspace TS 直消费、无 build 步骤"约定。

## 5. 一键启停脚本：`scripts/manage.sh`（Linux，服务器上跑）
分发子命令：
- `start`：检查 node≥20/pnpm → `node_modules` 缺则 `pnpm install` → `packages/client/dist` 缺则 `pnpm --filter @sgs/client exec vite build` → `pm2 delete sgs 2>/dev/null; pm2 start ecosystem.config.cjs` → `pm2 save` → 打印 `http://<本机IP>:8080`。
- `stop`：`pm2 delete sgs`。
- `restart`：`pm2 restart sgs`（或 stop+start）。
- `status`：`pm2 status sgs` + 提示端口。
- `logs`：`pm2 logs sgs --lines 50`。
- 无参时打印用法。
- 脚本 `cd` 到仓库根（`$(dirname "$0")/..`），幂等可重复跑。

## 6. README 部署段：`README.md`
追加"部署上云"小节：`git clone` →（阿里云安全组开 8080）→ `bash scripts/manage.sh start` → 浏览器开 `http://公网IP:8080`；关服 `bash scripts/manage.sh stop`；可选 `pm2 startup + pm2 save` 实现开机自启。注明走 `ws://IP:8080` 明文，公网长期建议后续加 nginx+wss。

## 7. .gitignore
- `packages/client/dist/` 已忽略（不动）；本次无新增需忽略产物（pm2 日志在 `~/.pm2/logs`，不入仓库）。

## 验收
1. `pnpm -r typecheck` 全过。
2. 本地模拟 prod：`pnpm --filter @sgs/client exec vite build` 出 dist → `PORT=8080 node --import tsx/esm packages/server/src/index.ts` 起 → 浏览器开 `http://localhost:8080` 能看到游戏页（不再是 vite:5173），且 ws 自动连上、能开房打牌（用之前两个标签的流程复测选将→对局）。
3. `bash scripts/manage.sh start` 本地能拉起 pm2（若装了 pm2）；`stop` 能停；`status/logs` 正常。
4. dev 回归：`pnpm dev` 仍 server:8080 + client:5173 双开正常，不受静态托管改动影响。
