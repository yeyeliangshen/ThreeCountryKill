# 三国杀：修两个 bug + 模式选择（军争/2v2）+ 扩武将

## 范围与取舍（先讲清楚）
- **本轮做**：① 修「选将不随机」(扩武将池到 ~12) ② 修「选将误触」(加确认步) ③ 模式选择框架 ④ 2v2 ⑤ 军争(身份)。
- **本轮不做（明确后续阶段）**：
  - **国战**：双将(`heroId[]`)+阵营(国别组队)+暗将/亮将，机制与身份模式差异最大，单列 Phase 2。
  - **卡牌规则复刻**：装备(武器/防具/±1坐骑)、锦囊(无中生有/过河拆桥/顺手牵羊/决斗/无懈可击/南蛮/万箭)、延时锦囊+判定(乐不思蜀/闪电)，单列 Phase 3。
  - **武将技能全量复刻**：本轮新增武将只实现「能套现有钩子」的少数技能(如龙胆/倾国)，其余以不同体力/国别作为白板武将，确保选将有变化即可；完整技能随 Phase 3 逐步补。

## 1. 扩武将池（修「选将不随机」）— `packages/engine/src/heroes.ts`
现状池仅 3 个 → 每人发到的永远是同一套。扩到 ~12 个：关羽/张飞(已有) + 赵云/马超/黄忠/吕布/貂蝉(群)/甄姬/司马懿/夏侯惇/许褚/华佗，并保留「平民」白板。
- 国别铺开 shu/wei/wu/qun/neutral，便于后续国战复用 `faction` 字段。
- **仅实现廉价技能**（套现有/小扩展钩子）：
  - 赵云·龙胆、甄姬·倾国：`canUseAs` 支持 `杀↔闪`/`黑牌→闪`，并扩展 `respondSha`/`respondDeath` 接受 `as`（见 §4）。
  - 许褚·裸衣：用现成的 `damageDealt` 钩子让杀伤害+1（顺带验证 hook 机制）。
  - 其余本轮为白板(仅体力/国别/技能文案)，技能复刻留 Phase 3。
- 池变 12 后，K=3 发将跨玩家真正随机化 → bug 消失。

## 2. 选将确认步（修「误触」）— `packages/client/src/pages/Game.tsx`
- draft 分支加本地 `pickedHero` 状态：点武将只高亮、不发；加「确认选择」按钮，点击才 `pickHero(pickedHero)`；可反复改选直到确认。
- prompt 变化时重置 `pickedHero`（沿用现有 useEffect 机制）。

## 3. 模式选择框架（协议+服务端+客户端）
**协议 `packages/protocol/src/`**（新增 `mode.ts` 或并入 views.ts）：
- `export type GameMode = 'junzheng' | '2v2' | 'melee' | 'guozhan'`
- `ClientMessage`: 加 `{ type:'setMode'; mode: GameMode }`（房主在大厅切换，实时广播给他人）；`startGame` 加 `mode: GameMode`。
- `ServerMessage.lobby`: 加 `mode: GameMode`。
- `Snapshot`: 加 `mode: GameMode`。
- `PlayerView`: 加 `role?: string | null`（仅本人可见，主公公开）、`team?: 0|1`（2v2 公开）。

**服务端 `packages/server/src/room.ts` + `index.ts`**：
- Room 加 `pendingMode: GameMode`(默认 `'melee'`)。`setMode` 仅房主可改，改完 `broadcastLobby()`。
- `startGame(seatId, { mode, heroDealCount })`：按模式校验人数——2v2 须 4 人；军争须 5–8 人；混战 ≥2。`createGame(setups, roomCode, { mode, heroDealCount })`。
- `index.ts`：处理 `setMode`；lobby 广播带 `mode`。

**客户端 `store.ts` + `Lobby.tsx`**：
- store 加 `mode` 状态 + `setMode` 动作(发 setMode) + `startGame` 带 mode。
- Lobby：房主见模式分段选择(军争/2v2/混战；国战置灰「敬请期待」)；非房主只读显示房主所选模式。「开始游戏」按模式校验人数(2v2==4、军争≥5、混战≥2)。

## 4. 引擎：2v2 + 军争规则 — `packages/engine/src/`
`model.ts`：
- `Player` 加 `role?: string`、`team?: 0|1`。
- `GameState` 加 `mode: GameMode`、`winner?: string`(阵营/队伍/身份方)。
- `createGame(seats, roomCode, { mode, heroDealCount })`：写入 mode；按模式分配 role/team：
  - **2v2**(须 4 人)：座次 1,3→team0；2,4→team1（A B A B）。
  - **军争**(5–8 人)：用标准身份表(5人=主1忠1反2内1；6=主1忠1反3内1；7=主1忠2反3内1；8=主1忠2反4内1)，随机洗入座次；主公 maxHp = 武将.maxHp+1。
  - **melee**：维持现状(无 role/team)。

胜负条件（替换 `doDeath` 里「≤1存活即结束」的纯死斗逻辑，改为 mode 分支）：
- **melee**：最后存活者胜（现状）。
- **2v2**：某队全灭 → 对方队胜；设 `winner='team0'/'team1'`。
- **军争**：主公阵亡 → 反贼方立即胜(`winner='rebel'`)；反贼与内奸全灭 → 主忠方胜(`winner='lord'`)；内奸须独活到最后(主忠反皆亡且仅剩内奸) → 内奸胜(`winner='renegade'`)。

身份可见性（`snapshot.ts` 裁剪）：
- 主公 role 对所有人公开；其余 role 仅本人快照里下发（他人视图 role=null）。
- 2v2 team 对所有人公开。
- 客户端 `Game.tsx`：自己头顶显示身份徽章(军争)/队伍色(2v2)；主公玩家加「主公」标记；回合信息显示模式；gameOver 显示胜方(「反贼胜利」「主忠方胜利」「蓝队胜利」等)。

`respondSha`/`respondDeath` 小扩展（服务赵云龙胆/甄姬倾国/华佗急救）：
- 被杀时除「闪」外，也接受 `heroCanUseAs(hero, card, 'shan')` 的牌(带 `as:'shan'`)；濒死救援同理接受 `as:'tao'`。
- `legal.ts` 的 respond 提示把可转化牌也列入 `legalCardIds`。
